本轮只写了两个主查询字符串；写入前确认两通道手动、六个方向/升降请求、托盘写入/清除请求均为 false，原主查询输入 LEN 和 20 个 DATA 字节均为 0。测试后恢复并核对这两个输入的 LEN/DATA 全部为 0。未写启动、停止、复位、自动、手动、禁用、方向、升降及托盘修改命令。

注意：恢复的是输入字符串，PLC 保留的选择、显示及查询缓存仍是本轮查询结果，详见问题 2。

## 已在线确认的问题

### 1. 出库设备误用入库 PLC 的状态数组

| 设备 | 当前推导的状态标签 | 在线结果 |
| --- | --- | --- |
| P3248 | SCADA_P[1,248].DeviceStatus | CIP 0x05 |
| P3249 | SCADA_P[1,249].DeviceStatus | CIP 0x05 |
| P3250 | SCADA_P[1,250].DeviceStatus | CIP 0x05 |
| P3251 | SCADA_P[1,251].DeviceStatus | CIP 0x05 |

离线 SCADA_P 的维度为 [2,153]，第二维有效下标 0～152。四台设备属于出库 PLC；按末三位直接推导入库 SCADA_P 地址不成立。此前用户确认空垛缓存及补盘接口尚未创建。

建议：这四台暂显示“出库 PLC 状态未接入”；以后配置真实出库 PLC 地址/标签，或由入库 PLC 接收专用状态接口。不能因读失败就显示自动、手动或无托盘，也不能通过修改外部访问权限解决下标问题。此次未擅自变更归属或 PLC 数组。

### 2. 清空主查询输入不会取消原选择

在线实测：

| 标签 | 1P | 3P |
| --- | --- | --- |
| HMI_Input_DeviceNo_<通道>_1 | 空字符串 | 空字符串 |
| HMI_DISPLAY_DeviceNo_<通道>_1 | P1025 | P1004 |
| AOI_HMI_ID_CHOOSE_<通道>.HMI_Man_No1 | 101025 | 101004 |
| HMI_DeviceNo_Convert_<通道>_1.Q_err | false | false |
| HMI_PalletInfo_<通道>.Device | 101025 | 101004 |

离线 DeviceNo_Convert 的 ST 仅在输入非空时处理，输入为空没有复位分支，与在线现象一致。主查询缓存和显示也没有随空输入清除。

建议：APP 始终以 PLC 选择回读明确展示“当前选择”；若产品约定清空即取消，需要 PLC 清除转换输出、选择结果并处理状态/托盘显示的有效性。按用户此前要求，APP 不自行改写或纠正设备编号。

## 离线发现、待当前在线工程导出确认

在线主查询联动正常，但当前目录 L5X 存在以下差异，不能直接认定在线也有这些故障。

1. 【用户已确认在线调用完成，不列为在线故障】目录文件的 MainProgram.MainRoutine 只有两个时钟梯级，没有调用 R01_Auto_Manual_1P、R02_Auto_Manual_3P、R05_HMI_DataProcess_1P、R06_HMI_DataProcess_3P；Zone_1P/Zone_3P/Data_Exchange 的主例程为空。用户随后确认子程序均已调用，且在线转换测试通过。此项仅记录导出文件与在线工程的差异，无需再次补调用。
2. R01_Auto_Manual_1P 与 R02_Auto_Manual_3P 的梯级 9～20 重复写 AOI_HMI_OP_Combine；3P 例程合并分支两侧均引用 3P。若按该文件同时调用，后执行的赋值可覆盖前面的合并结果。应由单一位置明确合并两通道。
3. 两个 HMI_DataProcess 例程的梯级 11/12 共用 MainProgram 作用域 TON_1/TON_2，预置均为 1000 ms；也共用 ons[0].0/.1。若同一扫描中先后调用，另一个通道的假条件可复位定时器，影响写入/清除完成。应为通道分配独立资源；1000 ms 与原 HMI 长按 3 秒的要求也需统一。此次未发托盘写入/清除命令验证。
4. DeviceNo_Convert 的 P 类条件为 >0 且 <=1153，减 1000 后直接用作下标；P1～P999 会产生负下标，P1153 对 [2,153] 数组越界。应在 PLC 内先验证边界，随后才能访问数组。未在线输入这些值，避免引发程序故障。
5. 禁用编号写入受 HMI_lock_1P/3P 约束。当前两者在线均为 false；不能仅凭 External Access 为读写，就认为禁用操作一定接受。第一版虽不做解锁按钮，仍需显示拒绝或实际结果。

## 已确认正确的绑定及边界

- 1P/3P 为同一入库 PLC 的两个 HMI 通道，65 项页面标签均可访问。
- 主查询编号使用各通道 HMI_Input_DeviceNo_*_1；状态及托盘查询使用 HMI_Status_Display_* / HMI_PalletInfo_*。
- 3P 的 P1004 查询实际回读 Device=101004，符合链条+移栽机数据在链条机中的约定。P1005 为 WCS 站点，不作为独立数据区替代 P1004；P1015/P1016 同理。
- 状态字 bit8/9/10 分别按自动、故障、有托盘解释。本轮仿真存在 512/1536 等状态字：应显示故障；其中 1536 同时表示有托盘。没有据此认定现场电机损坏。
- 启停、复位、点动、托盘修改/清除尚未进行功能写入测试；本报告不将可读等同于可动作。
