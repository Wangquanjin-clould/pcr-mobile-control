## 已修改

- WebView 的 `PLC_HOST`、原生 `LogixClient` 默认地址和 README 改为模拟器地址。
- 修正结构成员分隔符解析，支持 `HMI_Status_Display_1P.HMI_fault`、`HMI_PalletInfo_3P.PalletID.LEN` 等路径。
- 修正数组成员的 EPATH 编码：8 位下标使用 `28`，16/32 位下标带保留字节，支持二维数组和后续结构成员。
- 修正 Write Tag 请求顺序为数据类型、元素数量、数值；STRING 的 DATA 数组请求同步修正。

协议格式依据：[Rockwell 1756-PM020](https://literature.rockwellautomation.com/idc/groups/literature/documents/pm/1756-pm020_-en-p.pdf)，Write Tag 示例和 CIP Addressing Examples。
